# Viber expedition crew

Twelve portraits from the official Vibe Vibers raider gallery are hosted locally. The source page invites users to choose a Viber as a PFP and download its artwork; it does not state an open-source license or expressly describe game integration. No claim of ownership, endorsement, NFT ownership or broad commercial reuse rights is made. Confirm game-use rights with vibe/vibe before treating this as an official integration. Individual source URLs, attribution and hashes are in public/vibers/sources.json.

ATLAS names and roles are fictional. These are scripted quiz hosts, not autonomous AI services. The existing server question bank, answer secrecy, deadlines, scoring, 10 levels, username sessions and recovery remain untouched. Companion selection is cosmetic and stored only on the current device; it is not part of a recovered cloud passport.

The home page introduces the crew and supports companion selection and greetings. Hosts rotate deterministically across questions and levels. Correct server feedback triggers a short celebration; incorrect answers receive encouragement without revealing answers. Next remains immediately available. Reduced-motion preferences disable celebration motion; missing images fall back to initials.

Validation: run npm test and npm run build. Browser checks should cover practice correct/incorrect feedback, immediate Next, crew selection, a narrow viewport and returning to Explore. No production score mutations are needed for visual QA.
